Privacy Policy

Twitch Followers Viewer Extension

This Chrome extension is designed to display Twitch follower information directly within Twitch pages. ### Information Collection The extension may request a Twitch Client ID and Client Secret from the user in order to allow the user to make authenticated requests to the Twitch API using their own developer credentials. The extension does not collect, store, transmit, sell, or share any personal information, account credentials, browsing history, or user activity with the developer or any third parties. ### Credential Usage The provided Twitch API credentials are used locally within the extension only for the purpose of sending API requests directly to Twitch services on behalf of the user. No credentials are stored on external servers or transmitted to the developer. ### Data Storage Any data saved by the extension is stored locally within the user's browser storage only and is not accessible by the developer. ### Third-Party Services This extension interacts with the Twitch API to retrieve publicly available follower-related information. ### Changes to This Policy This privacy policy may be updated in the future to reflect improvements or changes to the extension functionality. ### Contact If you have any questions regarding this Privacy Policy, you may contact the developer through the Chrome Web Store listing.
